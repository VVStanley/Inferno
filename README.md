# Inferno

Inferno — одиночный 2D top-down шутер для Android: процедурный лабиринт, ограниченная видимость с фонариком и зомби. Первую рабочую версию создаём и проверяем на Linux/ПК.

## Стек
- Godot 4.7.x (предпочтительно 4.7.2)
- GDScript
- Android как целевая платформа

## Статус
Начальный каркас проекта. Игровой цикл и сцены ещё не реализованы.

## Как открыть
1. Установить совместимый Godot 4.7.x.
2. Открыть папку проекта в Godot Project Manager либо запустить `godot --editor --path .`.
3. После появления основной сцены её можно будет запустить из редактора.

## Проверка проекта
При установленном Godot: `godot --headless --path . --editor --quit`.
Это базовая проверка загрузки/импорта проекта, но не замена игрового тестирования.
